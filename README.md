# Ganesh Sharma — Portfolio

A modern personal portfolio website showcasing my projects, technical skills, professional experience, education, and certifications.

## ✨ Features

* Modern responsive portfolio design
* Premium light-themed UI
* Subtle 3D effects and animations
* Interactive hero section
* Project showcase with GitHub and live demo links
* Dynamic skills and technologies
* Experience and education timeline
* Certifications section
* Resume access
* Mobile-friendly design

## 🚀 Run Locally

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
